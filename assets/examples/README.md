# Gallery

Four chartbooks, each captured under ten Omarchy themes, straight from
`omacharts chartbook screenshot`. The app was driven entirely from the CLI.

Capped at 2000px wide (2600px for the collages) and saved as JPEG, so a clone
stays small. The lossless 4512x2732 originals are not in the repo.

## Layouts

| Chartbook | Layout | What it shows |
|---|---|---|
| `macro`  | 2x2 grid | SPY / TLT / GLD / BTC daily, SMA 50 + SMA 200, volume |
| `desk`   | big left, three stacked right | NVDA 1D / 1h / 15m / 5m on link group 4, volume profile on the daily, VWAP on the rest |
| `tape`   | one chart | SPY 5m with the whole stack: session volume profile, VWAP + 3 bands, EMA 21, volume, RSI, ATR |
| `crypto` | 1x3 row | BTC / ETH / SOL 1h, EMA 21 + EMA 55, volume, RSI |

## Themes

tokyo-night, catppuccin, gruvbox, nord, rose-pine, everforest,
catppuccin-latte, flexoki-light, matte-black, osaka-jade

Individual captures are `<layout>-<theme>.jpg`. Rose Pine renders light in this
Omarchy build, so it sits with the light themes rather than the dark ones.

## What is here

- `banner.jpg` — the image the README opens with
- `collages/themes-<layout>.jpg` — one layout across all ten themes
- `collages/layouts-<theme>.jpg` — all four layouts under one theme
- `collages/mosaic-*.jpg`, `collages/wide-strip.jpg` — mixed, layout and theme
  changing tile to tile
- `youtube/` — video thumbnails, with their 2560x1440 masters
- `screenshot.png`, `bar-widget.png` — earlier shots of the window and the
  Omarchy bar widget, kept for reuse
