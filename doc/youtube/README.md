# Video thumbnails

1280x720 for upload, 2560x1440 masters beside them to re-crop or resize from.

- `youtube-thumbnail-card.*` — wordmark on a solid card
- `youtube-thumbnail.*` — wordmark on a feathered band

The background is four captures from four chartbooks, each under a different
Omarchy theme, light and dark on a diagonal. Charts are dimmed only slightly;
the card or band is what carries the text contrast.
